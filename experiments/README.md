# Archived experiments

See [the experiment index](../docs/experiments.md) for the sequence of methods, entry points, dependencies and evaluation conventions.

Each dated directory keeps its own model/loss/evaluation versions and tests. Plans beside runners preserve historical settings and hashes; `../configs/` contains lighter parameter-only views. These runners need external event data and, for later campaigns, baseline checkpoints or frozen feature caches. They have not been retrained as part of publication.

`provenance.json` maps the included original files to their source-relative locations and hashes. RankSim's adapted file retains its CC BY-NC-SA 4.0 notice; consult that file and `methods_sweep_20261112/method_sources.txt` before reuse.
